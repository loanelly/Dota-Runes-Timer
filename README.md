## Dota-Runes-Timer 🎮⏱️
Простой графический таймер появления рун в Dota 2, написанный на Python с использованием библиотеки Tkinter. Он заранее (на отметке 1:40 и далее) предупреждает вас звуковым сигналом о появлении рун, помогая контролировать карту.
## ✨ Особенности

* Графический интерфейс: Удобное окно на базе Tkinter.
* Быстрый старт: Запуск в один клик через готовый .exe для Windows.
* Звуковые оповещения: Интеграция с системными звуками.
* Логирование: Все системные файлы и логи сохраняются в отдельной папке.

------------------------------
## 🚀 Инструкция по использованию (Windows)

   1. Перейдите в раздел Releases (Релизы).
   2. Скачайте актуальный файл Dota-Runes-Timer.exe.
   3. Запустите его. Всё, таймер готов к работе!

⚠️ Важно: Нажимайте кнопку запуска таймера ровно на отметке 00:00 на внутриигровых часах в Dota 2, чтобы время шло синхронно с матчем.

------------------------------
## 🍏 Информация для пользователей macOS
Готовый .exe файл предназначен только для Windows. Запуск оригинального Python-кода на macOS вызовет ошибку, так как скрипт использует встроенную Windows-библиотеку winsound для воспроизведения сигналов.
## Как адаптировать и запустить на macOS:

   1. Скачайте исходный код проекта.
   2. Откройте файл с кодом и замените модуль winsound на кроссплатформенную библиотеку для работы со звуком (например, playsound) или используйте системную команду macOS через os.system("afplay ...").
   3. Установите Tkinter (если он отсутствует) и запустите скрипт через Терминал:
   
   brew install python-tk
   python3 main.py
   
   4. Для сборки в самостоятельное macOS-приложение используйте pyinstaller:
   
   pip install pyinstaller
   pyinstaller --onefile --windowed main.py
